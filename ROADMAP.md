# Roadmap

## Marker improvements

Markers are already functional — they work as dedicated layers, scale to thousands
via `SharedLayer`, support styling and dynamic text. However, the styling
capabilities are still limited: it's not yet possible to easily create beautiful,
polished markers. Improving marker styling is the next development priority.

## Better extension points for third-party libraries

Some ideas for making the library more extensible are collected in
